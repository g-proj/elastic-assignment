# Frontend Development

This frontend uses Vite for development, testing, and production builds.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Starts the Vite development server on [http://localhost:3000](http://localhost:3000).

### `npm test`

Runs the Vitest test suite once.

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Serves the production build locally for a quick smoke test.
